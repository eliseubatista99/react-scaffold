# CV — Internationalisation and Resources

## Mechanism
- Built on core `useTranslations` (no React context). Each template passes its own `templateI18n: TranslationList` to `useTemplateHelper`, together with `props.language` (default `"en"`).
- Two kinds of text:
  1. **Labels** (section titles, months, link names, education types/status, language levels) → `t(key)`; when a key or language is missing the **raw key** is printed.
  2. **User data** fields typed `Translation` (`{ en, pt, ... }`) → `getTranslation(value)`; when the language entry is missing the result is `undefined` and the field is hidden (conditional rendering).
- Supported label languages: `en`, `pt`. Data can contain any language key, but labels would then fall back to raw keys.

## Base translations — `resources/translations.ts` (`CVTemplateBaseI18n`, internal)

| Group | Keys | en / pt examples |
|---|---|---|
| Links | `link.linkedin`, `link.github`, `link.portfolio`, `link.email`, `link.phone`, `link.other` | Phone / Telemóvel, Other / Outro |
| Time | `time.current`, `time.months.Jan` … `time.months.Dec` | Current / Atual; Feb / Fev, Apr / Abr, May / Mai, Aug / Ago, Sep / Set, Oct / Out, Dec / Dez |
| Education type | `education.type.secondary`, `.technical`, `.bachelor`, `.postgraduate`, `.master`, `.phd` | Bachelor's Degree / Licenciatura, Master's Degree / Mestrado, PhD / Doutoramento |
| Education status | `education.status.completed`, `education.status.in.progress`, `education.status.interrupted` | Completed / Completo, In Progress / Em andamento, Interrupted / Interrompido |
| Language level | `language.level.a1` … `language.level.c2`, `language.level.native` | A1…C2 (same in both), Native / Nativo |
| Sections | `section.professionalSummary.title`, `section.contacts.title`, `section.links.title`, `section.experience.title`, `section.education.title`, `section.skills.title`, `section.languages.title`, `section.certification.title`, `section.certification.action`, `section.volunteer.title`, `section.projects.title`, `section.projects.action`, `section.projects.source` | Professional Summary / Resumo Profissional, Technical Skills / Competências Técnicas, View Certificate / Ver Certificado, View Project / Ver Projeto, Source Code / Código Fonte |

Missing keys referenced by `useTemplateHelper`:
- `section.skillsAndLanguages.title` (not defined; not rendered by current templates).
- `education.status.progress` (the type value is `"progress"` but the dictionary key is `education.status.in.progress`) → Classic prints the raw key for in-progress education.

## Per-template overrides
| Template | File | Overrides |
|---|---|---|
| Classic | `templates/classic/classic.i18n.ts` | none (`{ ...CVTemplateBaseI18n }`) |
| Modern | `templates/modern/modern.i18n.ts` | `time.current` → en "Present", pt "Atual" |
| Timeline | `templates/timeline/timeline.i18n.ts` | `section.professionalSummary.title` → Summary / Resumo; `section.education.title` → Education / Educação; `section.experience.title` → Experience / Experiência |

To add a language, add the new key (e.g. `es`) to every entry in `translations.ts` and the template override files.

## Example data — `resources/exampleCV.ts` (`ExampleCvContent: CvData`, internal)
- Realistic author CV used only by stories: personal info, `linkedin` + `github` links, bilingual `resume`, 3 experiences (one with `current: true`), 2 education entries (master + bachelor, completed), bilingual comma-separated `skills`, 3 languages (`native`, `b2`, `a2`).
- `certifications: []`, `volunteers: []`, `projects: []` (four project examples are commented out in the file).
- Contains real personal contact details of the author; do not copy them into other files or tests.
