# Documentation and Context

- Write all context files and project documentation in English.
- Organize context and preference documents by category or area of responsibility.
- Keep guidance concise, actionable, and easy to discover; link to focused documents instead of duplicating their contents.
- Update documentation when a code change changes a public API, behavior, setup, or development workflow.
- Keep context files outside `ai-preferences/` up to date as project knowledge changes through our interactions.
- Modify files inside `ai-preferences/` only when the user explicitly asks to change their preferences.
